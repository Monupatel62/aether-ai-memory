# Research and Licenses — aether-ai-memory

## Candidate design areas
- Relational persistence for authoritative memory metadata and lifecycle.
- PostgreSQL full-text and pgvector as a baseline candidate, subject to the master data-infrastructure evaluation.
- Optional external vector stores only after measured quality/latency/cost need.

## Review requirements
Record exact package/release, license, transitive dependencies, data handling, security posture, and upgrade owner before adoption. Do not copy source code from research repositories without file-level license review.
